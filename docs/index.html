📚 How It Works

1. Data

Daily prices fetched via yfinance for all 20 Womack stocks. Historical returns & covariance matrix computed from 1-year lookback window.

2. Optimization

Bonmin MINLP solver maximizes Sharpe ratio subject to integer stock-selection binary variables and portfolio weight constraints.

3. Automation

GitHub Actions cron job runs the notebook daily at 6 AM UTC via Papermill. A Python script exports results to docs/portfolio_data.json.

4. Dashboard

GitHub Pages serves this dashboard from the docs/code> folder. On load, the page fetches portfolio_data.jsoncode> and renders live charts & tables.
