Pipeline
How the System Works End-to-End
01
Data Pull
yfinance downloads daily prices for all 20 stocks from March 2026 → today. S&P 500 list fetched from Wikipedia. Sector ETFs (XLK, XLC, XLV, XLB, XTN) downloaded.
02
Sliding Window
5-day rolling window computes mean returns and covariance matrix. Each window shifts 1 day forward — model re-optimizes every trading day.
03
Bonmin MINLP
Mixed-Integer Nonlinear solver picks exactly 10 stocks. Binary y[t] variables select stocks. Continuous x[t] sets proportions between 5%–25%.
04
Rotation Logic
3-day consecutive cap forces rotation. S&P 500 filter and ETF matching guide replacement choices toward quality, outperforming alternatives.
05
Comparison
Results compared vs S&P 500 buy & hold (SPY) and Golden Cross moving average strategy. Sharpe ratio, max drawdown, and win rate computed for all.
06
GitHub Actions
YAML cron job runs notebook at 9 AM EST every weekday. nbconvert generates this dashboard. Results committed and pushed automatically — zero manual work.
