📚 How It Works

1. Data

Daily prices fetched via yfinance for all 20 Womack stocks. Historical returns & covariance matrix computed.

2. Optimization

Bonmin MINLP solver maximizes Sharpe ratio subject to integer stock-selection binary variables and weight constraints.

3. Automation

GitHub Actions cron job runs notebook daily at 6 AM UTC via Papermill and commits updated outputs automatically.

4. Dashboard

GitHub Pages serves this dashboard from the docs/ folder. Charts update on each commit.
